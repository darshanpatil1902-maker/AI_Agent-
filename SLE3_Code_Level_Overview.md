## Main Code Elements

| Code element | Responsibility |
|---|---|
| input('You: ') | Accepts the user's question |
| question.lower() | Converts input to lowercase |
| if/elif | Selects the response using keyword conditions |
| Greeting conditions | Handles hello and hi |
| Topic conditions | Handles Python, AI and Machine Learning queries |
| Identity conditions | Handles name / identity questions |
| Help condition | Shows what the user can ask |
| exit + break | Ends the agent session |
| else | Gives a default response for unsupported input |

## Architecture Mapping

**User input → Input normalization → Keyword matching → Predefined response → Terminal output**
